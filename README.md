## **project_gen: Генератор структуры проектов на основе шаблонов**

**project_gen** — это инструмент на Python, предназначенный для автоматического создания файлов и папок новых проектов на основе предопределенных шаблонов.

### **✨ Ключевые особенности**

*   Использует движки шаблонов **Mustache** и **Jinja** для динамической генерации файлов с подстановкой переменных.
*   Встроенная функциональность для создания тестовых данных (фикстур), что упрощает начальную настройку проектов для тестирования.
*   Проект использует менеджер пакетов и зависимостей **Poetry**.
*   Включен `Dockerfile` для упаковки инструмента в контейнер.

### **🛠 Технологический стек**

*   **Язык**: Python
*   **Шаблонизация**: Mustache, Jinja
*   **Управление пакетами**: Poetry
*   **Конфигурация**: TOML
*   **Контейнеризация**: Docker

### **🚀 Начало работы**

1.  **Создание дистрибутивного пакета проекта**:
    ```bash
    poetry build
    ```
*  Генерирует два файла в директории dist/:

*  project_gen-0.1.0.tar.gz — исходный дистрибутив
*  project_gen-0.1.0-py3-none-any.whl — wheel-пакет

2.  **Установка или обновление пакета**:
    ```bash
    pip install project_gen-0.1.0.tar.gz --force-reinstall
    ```
*  Команда project_gen становится доступной в системе

3.  **Настройте конфигурационный файл**: Отредактируйте `testproject.toml`, указав параметры для нового проекта.

4.  **Инициализация проекта**:
    ```bash
    project_gen init
    ```

4.  **Генерация библиотек проекта**:
    ```bash
    project_gen setup
    ```

4.  **Генерация тестов проекта**:
    ```bash
    project_gen generate
    ```

### **📁 Структура проекта (основное)**

```
project_gen/
├── internal/                    # Внутренние модули генератора
├── templates/                   # Шаблоны для генерации проектов
├── utils/                       # Вспомогательные утилиты
├── pyproject.toml              # Конфигурация Poetry и зависимостей
├── poetry.lock                 # Фиксированные версии зависимостей
├── testproject.toml            # Пример конфигурационного файла
├── .gitignore
├── LICENSE
└── README.md
```

**📁 templates/ - коллекция шаблонов**

```
templates/
├── project/                    # Основной шаблон проекта
│   ├── .idea/                 # Настройки IDE PyCharm
│   │   └── inspectionProfiles/ # Профили инспекций кода
│   ├── hooks/                 # Скрипты-хуки для генерации
│   └── {{cookiecutter.project_name}}/  # Динамическое имя проекта
│       ├── checkers/          # Модули для проверок и валидации
│       ├── clients/           # Клиенты для внешних сервисов
│       │   └── http/          # HTTP-клиенты (aiohttp, requests)
│       ├── config/            # Конфигурационные файлы
│       ├── helpers/           # Вспомогательные модули
│       ├── services/          # Бизнес-логика, сервисный слой
│       └── tests/             # Тесты
│           ├── functional/    # Функциональные тесты
│           └── smoke/         # Smoke-тесты (проверка работоспособности)
├── python/                    # Python-специфичные шаблоны
│   └── asyncio/               # Шаблоны для асинхронного кода
└── tests/                     # Шаблоны для тестирования
```
